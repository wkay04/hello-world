### NY Assembly District 34 Interactive Map

An interactive, mobile-friendly map of New York Assembly District 34 built with Leaflet.js and OpenStreetMap.

**Quick Access:**
- 📱 [View Map on iPhone/Mobile](https://raw.githubusercontent.com/wkay04/hello-world/claude/ny-ad34-interactive-map-014gYAFtV5E6UMMt432YB1Vd/ny_ad34_map.html)
- 📄 [Setup Instructions](INSTRUCTIONS.md)
- 🚀 [Enable GitHub Pages](GITHUB_PAGES_SETUP.md) for a cleaner URL

**Features:**
- Zoomable OpenStreetMap tiles
- Official district boundaries from US Census
- Mobile-optimized touch controls
- Location finder for mobile devices
- Works instantly on iPhone, iPad, and any browser
